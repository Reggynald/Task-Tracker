# Task Tracker

Mein Projekt für die [roadmap.sh Task Tracker Challenge](https://roadmap.sh/projects/task-tracker-js) — ein kleiner Task-Tracker, mit dem man Aufgaben anlegen, bearbeiten und ihren Status verfolgen kann.

Es gibt zwei Varianten:

- **CLI** (`task-cli.js`) – läuft im Terminal mit Node.js, speichert alles in einer `tasks.json`
- **Browser-Version** (`index.html`) – läuft im Browser, speichert im LocalStorage

## CLI benutzen

Weitere Befehle: `mark-in-progress`, `list todo`, `list in-progress`, `list done`.

Jede Aufgabe hat eine ID, eine Beschreibung, einen Status (`todo`, `in-progress`, `done`) sowie Zeitstempel für Erstellung und letzte Änderung.
